## 🌟 Overview

**My DocuStack** is an exhaustive, production-grade developer reference handbook built with React and Vite. It unifies modern frontend engineering, backend services, high-throughput systems, relational databases, container orchestration, and cloud infrastructure into a single cohesive, blazingly fast documentation portal.

Every single method, tag, directive, and component is broken down into its own **dedicated, independent detail page** featuring:
- In-depth descriptions, execution mechanics, and architectural guidelines.
- **Interactive Live Previewers**: Real visual rendering for UI elements inside authentic **iOS Dynamic Island** and **Android Punch-Hole** mobile frames or browser viewports, and interactive **Developer Terminals & Runtime Consoles** for backend/DevOps APIs.
- Comprehensive runtime parameter tables, return signatures, and best-practice use cases.
- **Realistic, Production-Ready Code Examples** with zero artificial placeholder code or dummy logs.
- Dual-workflow setup blueprints complete with step-by-step terminal installation commands and project directory layout trees.

## ✨ Key Features

- 📱 **Dual Dynamic Preview System**:
  - **Mobile & Web Screens**: Visual UI elements (HTML, CSS, React, React Native, Next.js UI) display in responsive screen frames with Apple Dynamic Island and Android Punch-Hole camera options.
  - **Developer Runtime Console**: Backend, cloud, and database tools (Node.js, Go, Gin, GORM, Postgres, Docker, Kubernetes, AWS) display with an interactive terminal simulator.
- ⚡ **Separate, Granular Components**: No bundled or combined generic blocks. Every tag (e.g. `<header>`, `<nav>`, `<div>`) and method (e.g. `Array.map()`, `goroutine`, `c.JSON()`) has its own dedicated page.
- 🛠️ **Dual-Card Environment Setup Guides**: Every single technology includes an interactive setup tab with prerequisites, step-by-step terminal scripts, and full project folder structure trees.
- 📋 **Production-Grade Copyable Code**: Real-world, copyable code snippets with proper imports and return types. No placeholder dummy code or artificial `console.log` statements.
- 🎨 **Unified Corona Dark Theme**: Sleek obsidian backgrounds (`#000000` / `#0d0e12`), dark surface cards (`#191c24`), Emerald Green accents (`#00d25b`), and Neon Blue highlights (`#0090e7`).
- 🔍 **Instant Search & Filter**: Global `CTRL + K` instant search across all 480+ items, along with categorical filter chips.
- 📱 **100% Mobile & Desktop Responsive**: Fluid, mobile-friendly touch navigation with clean drawer menus and tablet/desktop grids.

## 🛠️ Getting Started

### Prerequisites
Make sure you have Node.js and npm installed:
- **Node.js**: `v18.0.0` or higher (Node.js 20+ LTS recommended)
- **npm**: `v9.0.0` or higher

### Installation & Development

1. **Clone the repository**:
   ```bash
   git clone https://github.com/satyam-umrao/react-native-docs.git
   cd react-native-docs
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start local development server**:
   ```bash
   npm run dev
   ```
   Open your browser and navigate to `http://localhost:3000/`.

4. **Build production bundle**:
   ```bash
   npm run build
   ```

5. **Preview production build locally**:
   ```bash
   npm run preview
   ```
