Setup

This guide is a practical React Native reference covering the major built-in UI components, common APIs, imports, dependency requirements, and styling options. Examples use modern functional components and hooks. The guide targets React Native 0.86-era APIs (the latest stable release as of August 2026), but most examples are intentionally version-neutral.

React Native CLI

npx @react-native-community/cli@latest init MyApp
cd MyApp
npm start

# In another terminal:
npm run android
# or
npm run ios

Expo

npx create-expo-app@latest MyApp
cd MyApp
npx expo start

Core Components

View

Container/layout primitive. No extra dependency.

Example
import { View, Text } from 'react-native';

export default function Example() {
  return (
    <View style={{ padding: 20, gap: 12 }}>
      <Text>Hello</Text>
      <Text>World</Text>
    </View>
  );
}

Text

Displays text; supports nesting and text-specific styling.

Example
import { Text, View } from 'react-native';

export default function Example() {
  return (
    <View>
      <Text style={{ fontSize: 22, fontWeight: '700' }}>
        Hello <Text style={{ color: 'tomato' }}>React Native</Text>
      </Text>
    </View>
  );
}

TextInput

Single-line or multiline keyboard input.

Example
import { useState } from 'react';
import { TextInput, View } from 'react-native';

export default function Example() {
  const [email, setEmail] = useState('');

  return (
    <View style={{ padding: 20 }}>
      <TextInput
        value={email}
        onChangeText={setEmail}
        placeholder="Email address"
        keyboardType="email-address"
        autoCapitalize="none"
        style={{ borderWidth: 1, borderRadius: 8, padding: 12 }}
      />
    </View>
  );
}

Button

Simple platform button for common actions. Limited styling; use Pressable for custom UI.

Example
import { Alert, Button, View } from 'react-native';

export default function Example() {
  return (
    <View style={{ padding: 20 }}>
      <Button
        title="Save"
        onPress={() => Alert.alert('Saved')}
      />

}

Pressable

Recommended flexible primitive for custom tappable controls.

Example
import { Pressable, Text } from 'react-native';

export default function Example() {
  return (
    <Pressable
      onPress={() => console.log('Pressed')}
      style={({ pressed }) => [
        { padding: 14, borderRadius: 10, backgroundColor: 'royalblue' },
        pressed && { opacity: 0.65 },
      ]}
      accessibilityRole="button"
      accessibilityLabel="Save item"
    >
      <Text style={{ color: 'white', textAlign: 'center', fontWeight: '700' }}>
        Save
      </Text>
    </Pressable>
  );
}

ScrollView

Scrollable container. Best for bounded/small content; renders all children.

Example
import { ScrollView, Text } from 'react-native';

export default function Example() {
  return (
    <ScrollView contentContainerStyle={{ padding: 20, gap: 12 }}>
      {Array.from({ length: 30 }, (_, i) => (
        <Text key={i}>Row {i + 1}</Text>
      ))}
    </ScrollView>
  );
}

FlatList

Virtualized list for performant one-dimensional lists.

Example
import { FlatList, Text, View } from 'react-native';

const data = [
  { id: '1', name: 'Apple' },
  { id: '2', name: 'Banana' },
  { id: '3', name: 'Orange' },
];

export default function Example() {
  return (
    <FlatList
      data={data}
      keyExtractor={(item) => item.id}
      renderItem={({ item }) => (
        <View style={{ padding: 16 }}>
          <Text>{item.name}</Text>
        </View>
      )}
      ItemSeparatorComponent={() => <View style={{ height: 1 }} />}
    />
  );
}

SectionList

Virtualized grouped/sectioned list.

Example
import { SectionList, Text, View } from 'react-native';

const sections = [
  { title: 'Fruits', data: ['Apple', 'Banana'] },
  { title: 'Vegetables', data: ['Carrot', 'Potato'] },
];

export default function Example() {
  return (
    <SectionList
      sections={sections}
      keyExtractor={(item, index) => `${item}-${index}`}
      renderSectionHeader={({ section }) => (
        <Text style={{ fontWeight: '700', padding: 12 }}>
          {section.title}
        </Text>
      )}
      renderItem={({ item }) => (
        <View style={{ padding: 12 }}>
          <Text>{item}</Text>
        </View>
      )}
    />
  );
}

Modal

Presents content above the current view.

Example
import { Modal, Pressable, Text, View } from 'react-native';
import { useState } from 'react';

export default function Example() {
  const [visible, setVisible] = useState(false);

  return (
    <View style={{ flex: 1, justifyContent: 'center', alignItems: 'center' }}>
      <Pressable onPress={() => setVisible(true)}>
        <Text>Open modal</Text>
      </Pressable>

      <Modal
        visible={visible}
        animationType="slide"
        transparent
        onRequestClose={() => setVisible(false)}
      >
        <View style={{
          flex: 1, justifyContent: 'center', alignItems: 'center',
          backgroundColor: 'rgba(0,0,0,0.4)'
        }}>
          <View style={{ padding: 24, backgroundColor: 'white', borderRadius: 16 }}>
            <Text style={{ marginBottom: 12 }}>Modal content</Text>
            <Pressable onPress={() => setVisible(false)}>
              <Text>Close</Text>
            </Pressable>
          </View>
        </View>
      </Modal>
    </View>
  );
}

RefreshControl

Pull-to-refresh control used with ScrollView/FlatList.

Example
import { useState } from 'react';
import { FlatList, RefreshControl, Text } from 'react-native';

export default function Example() {
  const [refreshing, setRefreshing] = useState(false);

  const refresh = async () => {
    setRefreshing(true);
    await new Promise((r) => setTimeout(r, 1000));
    setRefreshing(false);
  };

  return (
    <FlatList
      data={['One', 'Two', 'Three']}
      renderItem={({ item }) => <Text style={{ padding: 20 }}>{item}</Text>}
      keyExtractor={(item) => item}
      refreshControl={
        <RefreshControl refreshing={refreshing} onRefresh={refresh} />
      }
    />
  );
}

Dimensions / useWindowDimensions

Reads device/window dimensions; prefer the hook for responsive UI.

Example
import { Text, useWindowDimensions, View } from 'react-native';

export default function Example() {
  const { width, height, fontScale } = useWindowDimensions();

  return (
    <View style={{ padding: 20 }}>
      <Text>Width: {Math.round(width)}</Text>
      <Text>Height: {Math.round(height)}</Text>
      <Text>Font scale: {fontScale}</Text>
    </View>
  );
}

Runs platform-specific logic and selects platform-specific values/files.

Animated

Built-in animation API for values and transitions.

Example
import { useRef } from 'react';
import { Animated, Button, View } from 'react-native';

export default function Example() {
  const opacity = useRef(new Animated.Value(0)).current;

  const fadeIn = () => {
    Animated.timing(opacity, {
      toValue: 1,
      duration: 500,
      useNativeDriver: true,
    }).start();
  };

  return (
    <View style={{ padding: 20 }}>
      <Animated.View
        style={{
          width: 100,
          height: 100,
          backgroundColor: 'tomato',
          opacity,
        }}
      />
      <Button title="Fade in" onPress={fadeIn} />
    </View>
  );
}

Styling

React Native styles are JavaScript objects. Property names use camelCase. A style can be inline, created with StyleSheet.create(), or combined with an array. In an array, later styles override earlier styles.

1. StyleSheet

import { StyleSheet, Text, View } from 'react-native';

export default function Example() {
  return (
    <View style={styles.container}>
      <Text style={styles.title}>Hello</Text>
    </View>
  );
}

const styles = StyleSheet.create({
  container: {
    flex: 1,
    padding: 24,
    backgroundColor: '#f5f5f5',
  },
  title: {
    fontSize: 28,
    fontWeight: '700',
    color: '#111',
  },
});

2. Inline styles

import { View } from 'react-native';

export default function Example() {
  return (
    <View style={{
      padding: 20,
      marginTop: 10,
      backgroundColor: 'white',
      borderRadius: 12,
    }} />
  );
}

3. Style arrays / overrides

import { View } from 'react-native';

export default function Example({ active }) {
  return (
    <View
      style={[
        { padding: 16, backgroundColor: 'gray' },
        active && { backgroundColor: 'green' },
      ]}
    />
  );
}

4. Platform-specific styles

import { Platform, StyleSheet } from 'react-native';

const styles = StyleSheet.create({
  card: {
    padding: 16,
    ...Platform.select({
      ios: { shadowOpacity: 0.15, shadowRadius: 8 },
      android: { elevation: 4 },
      default: {},
    }),
  },
});

5. Responsive styling

import { StyleSheet, useWindowDimensions, View } from 'react-native';

export default function Example() {
  const { width } = useWindowDimensions();
  const isTablet = width >= 768;

  return (
    <View style={[
      styles.container,
      { padding: isTablet ? 32 : 16 }
    ]} />
  );
}

const styles = StyleSheet.create({
  container: {
    flex: 1,
  },
});

Useful Third-Party Dependencies

@react-navigation/native + @react-navigation/native-stack

Navigation between screens.

Install
npm install @react-navigation/native @react-navigation/native-stack
npx expo install react-native-screens react-native-safe-area-context
Example
import { NavigationContainer } from '@react-navigation/native';
import { createNativeStackNavigator } from '@react-navigation/native-stack';
import { Text, View } from 'react-native';

const Stack = createNativeStackNavigator();

function Home() {
  return <View><Text>Home</Text></View>;
}

function Details() {
  return <View><Text>Details</Text></View>;
}

export default function App() {
  return (
    <NavigationContainer>
      <Stack.Navigator>
        <Stack.Screen name="Home" component={Home} />
        <Stack.Screen name="Details" component={Details} />
      </Stack.Navigator>
    </NavigationContainer>
  );
}

Best Practices

  • Use FlatList/SectionList for large lists instead of rendering hundreds of children in ScrollView.
  • Use Pressable for new custom buttons and touch targets; keep Button for simple platform-native actions.
  • Keep reusable styles in StyleSheet.create() and use style arrays for conditional overrides.
  • Use useWindowDimensions() for responsive layouts rather than reading dimensions once at module load.
  • Always provide accessible labels/roles for custom controls and meaningful accessibilityLabel values for icon-only buttons.
  • Prefer react-native-safe-area-context instead of the deprecated core SafeAreaView.
  • Use stable keyExtractor values for lists; avoid array indexes when the item has a stable ID.
  • Keep expensive work out of renderItem; memoize rows when profiling shows avoidable re-renders.
  • Use KeyboardAvoidingView for forms and test both iOS and Android because keyboard behavior differs.
  • Use Platform.select() or .ios/.android files when platform-specific behavior is clearer than branching inline.
  • Prefer maintained libraries with New Architecture support for native functionality.
  • Check the library's compatibility with your React Native version before installing native dependencies.
